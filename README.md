# EuroDrive AI v0.1 — Android starter project

This is a small Android Studio source project for an early driving-practice prototype.
It contains a simple 2D road view, a car marker, traffic-light states, speed/brake controls,
left/straight/right controls, and rule-based instructor prompts.

## Important
- This is **not** a finished 3D simulator and it does not yet use AI or voice commands.
- It is a starter project to build on. Driving rules differ by European country.
- It is for practice/education only and does not replace lessons with a qualified instructor.

## Build an APK
1. Download and unzip this folder on a computer.
2. Install Android Studio.
3. In Android Studio, choose **Open** and select the unzipped `EuroDriveAI_v0_1` folder.
4. Allow Gradle sync to finish. If prompted, install the Android SDK (API 35).
5. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
6. Android Studio will show a notification with a link to the generated APK.

A computer with Android Studio is the easiest way to build this starter project. This ZIP itself is source code, not an installable APK.
